# BoardMate — фронтенд

Проста сторінка каталогу настільних ігор на HTML, CSS та JavaScript. Отримує дані з Django API через `fetch` і показує ігри в таблиці. Є перехід між сторінками, повідомлення про порожній каталог і помилку з’єднання.

## Як запустити проєкт

Потрібен Python 3. Спочатку запустіть [бекенд BoardMate](https://github.com/SigmaSigmaSigmaSigmaSigmaSigmaSigmaSigm/boardmate) за його README: `python manage.py runserver 8000`.

У папці фронтенду виконайте:

```sh
python3 -m http.server 5500 --bind 127.0.0.1
```

Відкрийте [фронтенд](http://127.0.0.1:5500/).

- Фронтенд: `http://127.0.0.1:5500/`.
- Бекенд: `http://127.0.0.1:8000/`.
- Запит каталогу: `http://127.0.0.1:8000/api/games/`.

Бекенд дозволяє CORS для `http://127.0.0.1:5500` та `http://localhost:5500`. Відкривайте сторінку через HTTP-сервер, а не як локальний файл. Залежностей JavaScript і кроку збірки немає.

Щоб додати ігри, скористайтеся JSON-запитами з README бекенду або його Postman-колекцією. Для демонстрації достатньо виконати запити створення категорії та гри.

## Використання ШІ

Codex допоміг написати сторінку й перевірки. Форматування перевіряється Prettier, HTML — HTML Validate, CSS — Stylelint. Результати перевірки браузером зазначені в PR бекенду.

## Перевірки

Для перевірок потрібен Node.js 22 або новіший:

```sh
npm ci
npm run check
```

Це запускає Prettier, HTML Validate, Stylelint та перевірку синтаксису JavaScript. Конфігурація HTML Validate враховує форматування Prettier.
